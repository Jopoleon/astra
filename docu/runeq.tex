\section{Generic transport equation}
\label{sec.traeq}
%
Some definitions:
\bea
&&\qt = \gblock \\
&&\qr := \qt - \bdot \rho y N  \\
&&\kappa = \frac{\rho}{\rho_b} \\
&&\ddt \frac{y}{\rho} - \rho \bdot \frac{\partial y}{\partial \rho} = D\left(\Psi\right) + S
\eea
The ASTRA generic transport equation reads:
\bean
&&S y + \pu = 
\ginv \ddt \gky_\rho + \vinv \ddr \left( V M \qr \right) = 
\ginv \ddt \gky_\rho + \vinv \ddr \left( V M \qt \right) - \frac{\bdot}{W} \ddr \left( \rho V M N y \right) = \\
&& = \ginv \ddt \gky_x - x \rbblock \ginv \ddx \gky + \vinv \ddr\left(V M \qt \right) - \frac{\bdot}{W} \ddr \left( \rho V M N y \right)
\eean
Substitung the definitions above, the explicit form reads:
\bean
&& \ginv \ddt \gky_x + \vinv \ddr \left[ VM \left( \gblock \right) \right] = \\
&& = Sy + \pu + \frac{bdot}{V} \vw \ddr \left( V M N \rho y \right) + \rbblock \frac{\rho}{V} \frac{V}{G} \ddr \gky
\eean
%
In implicit form, the transport equation looks like:
\bean
&& \ginv \ddt \gky_x + \vinv \ddr \left[VM \left( \gblock - \bdot \vw N \rho y - \rbblock \rho \frac{\kappa y}{M} \right) \right] = \\
&& = S y + \pu - \rbblock \frac{GHy}{V} \ddr R\left( \frac{\rho V}{G} \right) - \bdot M N \rho y \ddr \left( \vw \right) \\
\eean
