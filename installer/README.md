# ASTRA 8 на Ubuntu — быстрая установка

Транспортный код **ASTRA 8** ([gitlab.mpcdf.mpg.de/git/astra](https://gitlab.mpcdf.mpg.de/git/astra)) на обычном компьютере с Ubuntu, в том числе в WSL на Windows. Есть два независимых способа:

| способ | когда выбрать | как |
|---|---|---|
| **установщик** (без Docker) | обычная работа на своём ПК | этот файл, ниже |
| **Docker-образ** | не хочется ничего ставить в систему или нужна одинаковая среда у всех | [`docker/README.md`](docker/README.md) |

Подробности и объяснение, что и зачем меняется: [`docs/DETAILED.md`](docs/DETAILED.md).

Проверено 2026-10-01: чистые Ubuntu 22.04 (gfortran 11) и 24.04 (gfortran 13), WSL2 на Windows 11; ASTRA коммит `e66f6ba1` и свежий `main`.

## Что нужно

- Ubuntu 22.04 или 24.04 (64 бит), права `sudo`;
- интернет: ~500 МБ скачивания;
- ~2 ГБ на диске;
- для окна с графиками: рабочий стол Ubuntu или WSL2 на Windows 11 (там окна Linux открываются сами).

## Установка без Docker

Откройте терминал и выполните по очереди:

```bash
# 1. git, если его ещё нет
sudo apt update && sudo apt install -y git

# 2. скачать наш репозиторий и перейти в папку установщика
#    (не в ~/astra: туда ставится сама ASTRA)
git clone https://github.com/Jopoleon/astra.git ~/astra-repo
cd ~/astra-repo/installer

# 3. запустить установку (спросит пароль sudo и подтверждение)
bash install_astra8.sh
```

Установка занимает 3–10 минут, в основном на скачивание. Всё нужное (git, компилятор, библиотеки) скрипт ставит сам. В конце должно появиться:

```
  ok: ASTRA normal exit; result: /home/<вы>/astra/a8/ncdf_out/aug34954flux_feqis.CDF
==> Done
```

Это значит, что ASTRA собрана и тестовый расчёт прошёл. Если в конце написано `error: ...`, пришлите файл `~/astra/install.log` (и `~/astra/test_flux_feqis.log`, если он есть).

После установки **откройте новый терминал**, чтобы заработала команда `astra8`.

## Запуск

```bash
# повторить последний расчёт
astra8

# расчёт с окном графиков (как в ASTRA 7)
astra8 -m flux_feqis -v aug34954 -s 4 -e 5

# тот же расчёт без окна, результат пишется в файл
astra8 -m flux_feqis -v aug34954 -s 4 -e 5 -batch
```

Аргументы:

| ключ | что это | пример |
|---|---|---|
| `-m` | модель (файл в `~/astra/a8/equ/`) | `flux_feqis` |
| `-v` | экспериментальные данные (файл в `~/astra/a8/exp/`) | `aug34954` |
| `-s`, `-e` | время начала и конца расчёта, с | `-s 4 -e 5` |
| `-batch` | считать без окна | |

В ASTRA 7 запуск был `astra <данные> <модель>`; в ASTRA 8 это `astra8 -m <модель> -v <данные>`.

Где что лежит:

| папка | что там |
|---|---|
| `~/astra/a8/equ/` | модели (`showdata`, `flux_feqis`, ...) — сюда класть свои |
| `~/astra/a8/exp/` | файлы эксперимента (`readme`, `aug34954`, ...) |
| `~/astra/a8/udb/` | U-файлы, на которые ссылаются файлы эксперимента |
| `~/astra/a8/ncdf_out/` | результаты (`<данные><модель>.CDF`) |

## TGLF (по желанию)

TGLF — открытая модель турбулентного переноса из пакета GACODE ([github.com/gafusion/gacode](https://github.com/gafusion/gacode)). По умолчанию не ставится; чтобы поставить, добавьте ключ:

```bash
bash install_astra8.sh --with-tglf
```

Скрипт доставит OpenMPI из apt, скачает нужную часть GACODE (~13 МБ) и соберёт TGLF (≈10 с). Установка станет дольше примерно на 2 минуты: в конце дополнительно прогоняется тестовый расчёт `flux_tglf` (в нём TGLF вызывается дважды). Должно появиться:

```
  ok: ASTRA normal exit with TGLF; result: /home/<вы>/astra/a8/ncdf_out/aug34954flux_tglf.CDF
```

Модели с TGLF: `flux_tglf`, `tglf`, `tglf_pid` (параллельный вариант через `xpr/tglfi`) и `flux_tglf_serial`, `tglf_serial` (последовательный, в разы медленнее). Пример:

```bash
astra8 -m flux_tglf -v aug34954 -s 4 -e 4.5 -batch
```

Каждый вызов TGLF запускает 64 процесса — по одному на точку радиальной сетки — и они делят ядра компьютера. На 12 физических ядрах один вызов идёт ~30 с, на 4 ядрах — оценочно 1–2 минуты. Как часто вызывать TGLF, задаёт модель (`TGLF_IPC<:0.1:::;` — раз в 0.1 с времени разряда).

Ключ `--with-neo` так же собирает NEO (неоклассика, модель `flux_neo`), но это экспериментально: на ПК расчёт не проверен, 64 процесса NEO занимают по 1–4 ГБ памяти каждый.

После установки TGLF остаётся включённым и при повторных запусках скрипта без ключа.

## SPIDER и STRAHL из ASTRA 7 (если есть своя копия A7)

SPIDER (равновесие, `IPEQL=4`) и STRAHL (примеси, `A2STRAHL`) — закрытые коды IPP. Скрипт их **не скачивает**: он собирает их из вашей локальной копии ASTRA 7, если она есть.

```bash
bash install_astra8.sh --a7-src /путь/к/ASTRA_7.02 --strahl-src /путь/к/ASTRA_STRAHL/STRAHL
```

`--a7-src` — каталог, в котором есть `EQUIL/SPIDER/SRC` и `MAstraN/`. После установки дополнительно прогоняются `flux_spider` и `astrahl_simple_msp`. Свободная граница со SPIDER не проверена. Подробности — `docs/research/spider-strahl-from-a7-2026-10-02.md` в корне репозитория.

## Перенос моделей и данных из ASTRA 7

Установщик исправляет ASTRA 8 так, чтобы она читала файлы эксперимента A7 и собирала модели A7. Модель вместе с её формулами переносит команда `astra8-a7to8`:

```bash
astra8-a7to8 /путь/к/A7/user ~/astra/a8 МОДЕЛЬ.model --exp ДАННЫЕ.data
astra8 -m МОДЕЛЬ -v ДАННЫЕ.data -s 0.15 -e 0.2
```

Что она делает и что проверить руками — `docs/research/a7-user-area-to-a8-2026-10-02.md`. Главное:

- `ITFBE = -1` в A7 ничего не включал (без `ITFBP`), а в A8 включает свободную границу. Для заданной границы ставьте `ITFBE = 1e6;`.
- `ABC` в `equ/log/<модель>` должен быть не больше малого радиуса границы.

## Что не работает в этой сборке

- **RABBIT** (NBI) и **TORBEAM** (ECRH) — закрытые коды IPP, без доступа к их GitLab их не поставить. В тестовой модели `flux_feqis` они отключены. SPIDER и STRAHL — см. выше.
- **QuaLiKiZ, QLKNN** — открытые, но пока не ставятся этим скриптом. **NEO** — только сборка (см. выше).
- `astra8 -m showdata -v readme` не работает в ASTRA 8: модель `showdata` написана для A7, а в `exp/readme` есть два формата A7, которые ASTRA 8 не читает (одномерный U-файл и блок `POINTS`). Рабочие файлы лаборатории читаются.

## Повторный запуск и обновление

Скрипт можно запускать повторно: уже сделанное пропускается, ваши файлы в `equ/`, `exp/`, `udb/` не перезаписываются.

```bash
bash install_astra8.sh --ref main     # обновиться до свежей версии ASTRA
bash install_astra8.sh --help         # все параметры
```
