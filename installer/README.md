# ASTRA 8 на Ubuntu — быстрая установка

Транспортный код **ASTRA 8** ([gitlab.mpcdf.mpg.de/git/astra](https://gitlab.mpcdf.mpg.de/git/astra)) на обычном компьютере с Ubuntu, в том числе в WSL на Windows. Есть два независимых способа:

| способ | когда выбрать | как |
|---|---|---|
| **установщик** (без Docker) | обычная работа на своём ПК | этот файл, ниже |
| **Docker-образ** | не хочется ничего ставить в систему или нужна одинаковая среда у всех | [`docker/README.md`](docker/README.md) |

Подробности и объяснение, что и зачем меняется: [`docs/DETAILED.md`](docs/DETAILED.md).

Проверено 2026-10-01: чистые Ubuntu 22.04 (gfortran 11) и 24.04 (gfortran 13), WSL2 на Windows 11; ASTRA коммит `e66f6ba1` и свежий `main`.

## Что нужно

- Ubuntu 22.04 или 24.04 (64 бит), права `sudo`;
- интернет: ~500 МБ скачивания;
- ~2 ГБ на диске;
- для окна с графиками: рабочий стол Ubuntu или WSL2 на Windows 11 (там окна Linux открываются сами).

## Установка без Docker

Откройте терминал и выполните по очереди:

```bash
# 1. git, если его ещё нет
sudo apt update && sudo apt install -y git

# 2. скачать наш репозиторий и перейти в папку установщика
#    (не в ~/astra: туда ставится сама ASTRA)
git clone https://github.com/Jopoleon/astra.git ~/astra-repo
cd ~/astra-repo/installer

# 3. запустить установку (спросит пароль sudo и подтверждение)
bash install_astra8.sh
```

Установка занимает 3–10 минут, в основном на скачивание. Всё нужное (git, компилятор, библиотеки) скрипт ставит сам. В конце должно появиться:

```
  ok: ASTRA normal exit; result: /home/<вы>/astra/a8/ncdf_out/aug34954flux_feqis.CDF
==> Done
```

Это значит, что ASTRA собрана и тестовый расчёт прошёл. Если в конце написано `error: ...`, пришлите файл `~/astra/install.log` (и `~/astra/test_flux_feqis.log`, если он есть).

После установки **откройте новый терминал**, чтобы заработала команда `astra8`.

## Запуск

```bash
# повторить последний расчёт
astra8

# расчёт с окном графиков (как в ASTRA 7)
astra8 -m flux_feqis -v aug34954 -s 4 -e 5

# тот же расчёт без окна, результат пишется в файл
astra8 -m flux_feqis -v aug34954 -s 4 -e 5 -batch
```

Аргументы:

| ключ | что это | пример |
|---|---|---|
| `-m` | модель (файл в `~/astra/a8/equ/`) | `flux_feqis` |
| `-v` | экспериментальные данные (файл в `~/astra/a8/exp/`) | `aug34954` |
| `-s`, `-e` | время начала и конца расчёта, с | `-s 4 -e 5` |
| `-batch` | считать без окна | |

В ASTRA 7 запуск был `astra <данные> <модель>`; в ASTRA 8 это `astra8 -m <модель> -v <данные>`.

Где что лежит:

| папка | что там |
|---|---|
| `~/astra/a8/equ/` | модели (`showdata`, `flux_feqis`, ...) — сюда класть свои |
| `~/astra/a8/exp/` | файлы эксперимента (`readme`, `aug34954`, ...) |
| `~/astra/a8/udb/` | U-файлы, на которые ссылаются файлы эксперимента |
| `~/astra/a8/ncdf_out/` | результаты (`<данные><модель>.CDF`) |

## Что не работает в этой сборке

- **RABBIT** (NBI), **TORBEAM** (ECRH), **SPIDER**, **STRAHL** — закрытые коды IPP, без доступа к их GitLab их не поставить. В тестовой модели `flux_feqis` они отключены.
- **TGLF, NEO, QuaLiKiZ** — открытые, но пока не ставятся этим скриптом.
- `astra8 -m showdata -v readme` из репозитория не запускается: файл `exp/readme` ссылается на U-файлы `00000.tes`/`00000.tis`, которых в репозитории нет, и написан в формате ASTRA 7. Нужны файлы из рабочей установки ASTRA 7.

## Повторный запуск и обновление

Скрипт можно запускать повторно: уже сделанное пропускается, ваши файлы в `equ/`, `exp/`, `udb/` не перезаписываются.

```bash
bash install_astra8.sh --ref main     # обновиться до свежей версии ASTRA
bash install_astra8.sh --help         # все параметры
```
