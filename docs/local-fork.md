# Форк ASTRA (`astra-src/`)

## Что это

`astra-src/` — исходники транспортного кода **ASTRA 8** вместе с историей оригинала,
включённые в этот репозиторий через `git subtree`:

- оригинал: <https://gitlab.mpcdf.mpg.de/git/astra.git>
- мейнтейнеры оригинала: Giovanni Tardini, Emiliano Fable (IPP, Garching)
- лицензия: **GNU LGPL v2.1 или новее** (файл `astra-src/LICENSE`)

Копию держим у себя, чтобы:

- разбираться, как ASTRA устроена (анализ кода, документация: `astra-src/docs/`);
- исправлять то, что мешает работе на обычной Ubuntu (см. установщик);
- при необходимости расширять функциональность;
- изучать, как ASTRA настроена на других площадках (`platform/env.*` — IPP, ITER, GA, NERSC, ...).

Из исходников **ничего не вычищаем** без отдельного решения: чужие площадки, модули, данные —
материал для изучения.

## Что отличается от оригинала

История оригинала весит ~1 ГБ и содержит файлы по 215 МБ, которые GitHub не принимает. Поэтому
она пропущена через `git filter-repo` с фильтром:

```
--path regressions/ --invert-paths --strip-blobs-bigger-than 5M
```

- убраны `regressions/` (эталонные CDF, ~180 МБ) и все файлы больше 5 МБ за всю историю
  (кроме regressions это были только старые бинарники закрытого RABBIT и `xtglf`
  в `pre_compiled_libs/`, в текущих исходниках их нет);
- все 1794 коммита оригинала на месте, авторы и даты сохранены, история весит ~71 МБ;
- хэши коммитов **отличаются** от MPCDF — это следствие фильтра;
- фильтр детерминирован: одна и та же история даёт одни и те же хэши, поэтому каждая
  синхронизация только дописывает новые коммиты.

Regressions локально лежат в полном клоне `.upstream/mpcdf/regressions/` (см. ниже).

## Устройство

| что | где | в GitHub |
|---|---|---|
| исходники ASTRA + наши правки | `astra-src/` в ветке `main` | да |
| очищенная копия MPCDF, руками не трогаем | ветка `astra-upstream` | да |
| последняя синхронизация (хэши MPCDF и очищенный) | `tools/upstream-sync.txt` | да |
| полный клон MPCDF (~1 ГБ, с regressions) | `.upstream/mpcdf/` | нет, `.gitignore` |
| очищенная копия, промежуточная | `.upstream/filtered/` | нет, `.gitignore` |

Наши правки в ASTRA — обычные коммиты в `astra-src/` этого репозитория. Что мы изменили
относительно оригинала (в `astra-upstream` файлы лежат в корне, без префикса `astra-src/`):

```bash
git diff --stat astra-upstream: HEAD:astra-src
git log --oneline astra-upstream..HEAD -- astra-src
```

## Как подтягивать обновления оригинала

```bash
tools/sync-upstream.sh
git push origin main astra-upstream
```

**Важно: обновления подтягиваются не голым `git pull` с MPCDF, а командой
`tools/sync-upstream.sh`.** Голый `pull` притащит неочищенную историю (~1 ГБ, файлы по 215 МБ),
потому что у очищенной истории другие хэши. Для нас разница только в команде, результат тот же.
В скрипт заложены две проверки:

- если в новых коммитах MPCDF что-то вырезано фильтром, скрипт выведет список, чтобы нужный
  файл не пропал молча (взять его можно вручную из `.upstream/mpcdf`);
- если MPCDF когда-нибудь перепишет свою историю (бывает редко), скрипт остановится
  и ничего не сломает.

Что делает скрипт по шагам:

1. `fetch` MPCDF в `.upstream/mpcdf` (при первом запуске клонирует, ~1 ГБ);
2. останавливается, если прошлый синхронизированный коммит MPCDF не предок нового;
3. печатает, что фильтр вырежет из новых коммитов;
4. заново очищает историю тем же фильтром в `.upstream/filtered`;
5. останавливается, если очищенная история не продолжает `astra-upstream`;
6. продвигает `astra-upstream`, записывает `tools/upstream-sync.txt` отдельным коммитом;
7. `git subtree merge --prefix=astra-src astra-upstream` — наши правки сохраняются,
   конфликты разрешаются как при обычном merge.

Ничего не пушит. Нужен `git-filter-repo` (`sudo apt install git-filter-repo`).
Проверено 2026-10-01 на имитации обновления `e66f6ba1..67281112`, на остановке при
переписанной истории и на списке вырезанного.

Обновления берём по необходимости. При конфликтах приоритет у наших сознательных правок;
изменения оригинала в физике и численных схемах — смотреть внимательно.

## Лицензия и права

Форк и правки разрешены LGPL. Обязательно:

- сохранять `astra-src/LICENSE`, копирайты и авторство оригинала;
- изменённая ASTRA распространяется под LGPL с указанием, что это модифицированная версия
  и откуда взят оригинал (этот документ и `README.md`).

Наш код вокруг ASTRA пока остаётся открытым.

## Окончания строк

В `~/.gitconfig` стоит `core.autocrlf=true` (WSL/Windows), а с CRLF скрипты ASTRA не работают.
В этом репозитории `core.autocrlf=false` задан локально и есть `.gitattributes` с `eol=lf`;
скрипт синхронизации выключает autocrlf и в `.upstream/`.
