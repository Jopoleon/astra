# Локальный форк ASTRA (`astra-src/`)

## Что это

`astra-src/` — полная копия (с историей git) исходников транспортного кода **ASTRA 8**
из оригинального репозитория IPP:

- оригинал: <https://gitlab.mpcdf.mpg.de/git/astra.git>
- мейнтейнеры оригинала: Giovanni Tardini, Emiliano Fable (IPP, Garching)
- лицензия: **GNU LGPL v2.1 или новее** (файл `astra-src/LICENSE`)

Копию держим у себя, чтобы:

- разбираться, как ASTRA устроена (анализ кода, документация для себя);
- исправлять то, что мешает работе на обычной Ubuntu (см. установщик);
- при необходимости расширять функциональность;
- изучать, как ASTRA настроена на других площадках (`platform/env.*` — IPP, ITER, GA, NERSC, ...).

Из копии **ничего не вычищаем** без отдельного решения: регрессии, чужие площадки, модули —
всё это материал для изучения.

## Почему в `.gitignore`

Папка `astra-src/` в этот репозиторий **не коммитится**:

- история оригинала весит ~1 ГБ и содержит файлы по 215 МБ, которые GitHub не принимает;
- у копии свой git — так видно, что изменили мы, а что пришло из оригинала.

Этот репозиторий (`Jopoleon/astra`) — монорепо: установщик, документация, разборы ASTRA.

## Лицензия и права

Форк и правки разрешены LGPL. Обязательно:

- сохранять `LICENSE`, копирайты и авторство оригинала;

## Устройство git в `astra-src/`

| ветка / remote | назначение |
|---|---|
| remote `upstream` | оригинал MPCDF (только чтение) |
| `main` | точная копия `upstream/main`, руками не правим |
| `local` | **наша рабочая ветка**: фиксы, удаления, доработки |

Восстановить копию с нуля:

```bash
git clone https://gitlab.mpcdf.mpg.de/git/astra.git astra-src
cd astra-src
git remote rename origin upstream
git switch -c local
git config core.autocrlf false && git config core.eol lf
git rm --cached -r -q . && git reset -q --hard   # перевыкачать файлы с LF
```

Важно: в `~/.gitconfig` стоит `core.autocrlf=true` (WSL/Windows), с CRLF скрипты ASTRA не работают.
Поэтому в `astra-src/` и в этом репозитории `core.autocrlf=false` задан локально.

(Наши правки из ветки `local` при этом не восстановятся — они живут только на диске,
пока не решим, куда их публиковать.)

## Как подтягивать обновления оригинала

```bash
cd astra-src
git fetch upstream
git switch main && git merge --ff-only upstream/main
git switch local && git merge main      # или cherry-pick нужных коммитов
```

Обновления берём по необходимости, не обязательно все. При конфликтах приоритет у наших правок,
если они сознательные; изменения оригинала в физике/численных схемах — смотреть внимательно.
