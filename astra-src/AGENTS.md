# AGENTS.md (astra-src)

Инструкции для агентов, работающих внутри `astra-src/` — локального форка исходников транспортного кода **ASTRA 8**. Язык документации — русский. Состояние описано на 2026-10-01, коммит `67281112` (ветка `local` = `upstream/main`).

Этот файл дополняет корневой [`../AGENTS.md`](../AGENTS.md) монорепозитория (установщик, лаборатория, правила проверки). Здесь — только то, что касается исходников ASTRA.

## Ключевые факты (не переоткрывать)

- Исполняемый файл собирается **заново под каждую пару модель + эксперимент**: `exe/as_exe` → `exe/as_exe.py` → `exe/Build` → `get_platform` + `platform/env.<platform>` + `exe/astra_rc` → `make` (парсер `pyparse/` переводит `equ/<модель>` и `exp/<эксперимент>` в Fortran) → `bin/<модель>_{gui,batch}.exe` → `json2cdf` → `ncdf_out/*.CDF`.
- `repo_user_area/` копируется `install.sh` в пользовательскую область (`equ/`, `exp/`, `udb/`, `exe/`, `sbr/`, `fnc/`, `fml/`, `xpr/`, ...), которая игнорируется git оригинала. Правка `repo_user_area/` не меняет уже установленную пользовательскую область.
- Ядро — Fortran (`src/astra`, `src/feqis`, `src/nbi`, `src/graph`, `src/misc`), генератор кода и чтение данных — Python (`pyparse/`), постобработка — `postProcess/`.
- Закрытые коды IPP (RABBIT, TORBEAM, SPIDER, STRAHL) в дереве представлены только интерфейсами/заглушками. Не пытаться их добыть и не публиковать.
- `exe/as_exe` возвращает 0 даже при ошибке: успех = `>>> ASTRA normal exit >>>` в выводе + CDF в `ncdf_out/`.
- Мануал оригинала — `docu/` (LaTeX: `main.tex` = IPP 5/98, 2002, для A6/A7; `addendum_A8.tex` — изменения A8; `FEQIS_manual.tex`, `IPC.tex`, стеллараторные документы). Наша документация на русском — `docs/`.

## Правила работы

- Ветки: `main` — точная копия `upstream/main`, руками не трогать; `local` — наша рабочая ветка, все правки только здесь.
- Значимые правки исходников записывать в журнал [`../docs/local-fork.md`](../docs/local-fork.md) и, если меняется описанное поведение, — в соответствующую главу `docs/`.
- Ничего не удалять по своей инициативе: чужие `platform/env.*`, `regressions/`, модули, старые скрипты — материал для изучения.
- Не пушить `astra-src/` в GitHub: в истории оригинала есть файлы >100 МБ.
- Сохранять `LICENSE`, копирайты и авторство. Изменённая ASTRA при распространении — под LGPL, с пометкой, что версия модифицирована, и ссылкой на оригинал.
- Окончания строк только LF (`core.autocrlf=false` задан локально): с CRLF скрипты ASTRA падают с `required file not found`.
- Не собирать и не запускать расчёты внутри `astra-src/`: для экспериментов есть рабочая установка `~/astra/a8` (или копия во `/tmp`). Сборка мусорит в `tmp/`, `obj/`, `mod/`, `bin/`, `ncdf_out/`.
- Коммитить только по просьбе пользователя.
