# ASTRA 8 — наш форк и обвязка

Рабочий репозиторий для транспортного кода **ASTRA 8**
(оригинал: <https://gitlab.mpcdf.mpg.de/git/astra.git>, IPP, лицензия LGPL v2.1+).

Задачи:

- держать у себя исходники ASTRA для анализа и доработки;
- поддерживать установку на обычной Ubuntu (в перспективе — пакет `apt`);
- документировать, как ASTRA устроена и что мы в ней меняем.

## Структура

| путь | что |
|---|---|
| `astra-src/` | локальный форк исходников ASTRA, **в `.gitignore`**, свой git — см. [docs/local-fork.md](docs/local-fork.md) |
| `docs/` | документация |

## Лицензия

ASTRA распространяется под GNU LGPL v2.1 (или новее), авторские права принадлежат её авторам
(IPP). `astra-src/` — модифицированная нами копия, правки в ней подпадают под ту же лицензию.
