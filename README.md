# ASTRA 8: установщик, исходники и изучение

Монорепозиторий всего, что мы делаем вокруг транспортного кода **ASTRA 8**
(оригинал: <https://gitlab.mpcdf.mpg.de/git/astra.git>, IPP Garching, лицензия LGPL v2.1+).

## Зачем

1. **Рабочий установщик ASTRA 8 для обычной Ubuntu** (в т.ч. WSL) для лаборатории: Никите
   и коллегам нужно ставить и запускать ASTRA на чистой системе. В перспективе — пакет `apt`.
2. **Понять и изучить ASTRA**: как она устроена, как собирается, как настроена на других площадках,
   какие у неё модели и внешние модули. Для этого исходники лежат рядом, в `astra-src/`.

## Структура

| путь | что | в git |
|---|---|---|
| [`installer/`](installer/) | установщик `install_astra8.sh`, Docker-вариант, инструкции для пользователей | да |
| [`docs/`](docs/README.md) | документация: форк, изучение ASTRA, исследования | да |
| `astra-src/` | локальный форк исходников ASTRA со своим git ([как устроен](docs/local-fork.md)) | **нет**, в `.gitignore` |
| `astra-src/docs/` | подробная документация по исходникам ASTRA на русском (12 глав: устройство, сборка, язык модели, данные, ядро, равновесие, нагрев, вывод, каталог моделей, использование на токамаке, руководство, глоссарий); вход — `astra-src/docs/README.md`, для агентов — `astra-src/AGENTS.md` | **нет**, только локально (ветка `local` форка) |

## Быстрый старт

Поставить ASTRA (подробно — [`installer/README.md`](installer/README.md)):

```bash
git clone https://github.com/Jopoleon/astra.git ~/astra-repo
cd ~/astra-repo/installer
bash install_astra8.sh
astra8 -m flux_feqis -v aug34954 -s 4 -e 5
```

Получить исходники ASTRA для изучения (рядом с репозиторием, в `astra-src/`) — см.
[`docs/local-fork.md`](docs/local-fork.md).

## Лицензия

ASTRA распространяется под GNU LGPL v2.1 (или новее), авторские права принадлежат её авторам
(IPP). `astra-src/` — наша модифицируемая копия, правки в ней подпадают под ту же лицензию.
Наш собственный код и документация в этом репозитории пока открытые.
