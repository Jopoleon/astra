# CLAUDE.md

Монорепо вокруг транспортного кода ASTRA 8 (github.com/Jopoleon/astra). Язык документации — русский.

Полные инструкции для агентов, всё уже выясненное и чек-лист проверки — в `AGENTS.md`. Его читать первым;
этот файл — краткая выжимка.

Цели: (1) рабочий установщик ASTRA 8 для обычной Ubuntu/WSL для лаборатории (Никита и коллеги),
в перспективе apt-пакет; (2) изучить и понять, как ASTRA устроена.

## Структура

- `installer/` — `install_astra8.sh`, `docker/`, `docs/DETAILED.md` (устройство сборки ASTRA и все патчи для Ubuntu).
- `docs/` — документация, оглавление в `docs/README.md`; разборы ASTRA — в `docs/astra/`.
- `astra-src/` — локальный форк исходников ASTRA (MPCDF, LGPL v2.1+). В `.gitignore`, свой git:
  remote `upstream` = MPCDF, `main` = копия оригинала (не трогать), `local` = наша рабочая ветка.
  Подробно: `docs/local-fork.md`. Документация по исходникам (12 глав) — `astra-src/docs/README.md`,
  вводные для агентов — `astra-src/AGENTS.md` (только локально).

## Правила

- Ничего не вычищать из `astra-src/` по своей инициативе: чужие `platform/env.*`, регрессии,
  модули и т.п. — материал для изучения. Удаляем только по явной просьбе.
- Правки исходников ASTRA — только в `astra-src/` на ветке `local`, коммиты там же; значимые правки
  записывать в журнал в `docs/local-fork.md`.
- Не пушить `astra-src/` в GitHub: в истории оригинала есть файлы >100 МБ.
- Соблюдать LGPL: не удалять `LICENSE` и копирайты оригинала.
- Окончания строк только LF (в `~/.gitconfig` стоит `autocrlf=true`, локально выключено; с CRLF
  скрипты ASTRA ломаются).
- Установщик по умолчанию ставит ASTRA в `~/astra` — не клонировать этот репозиторий туда.
- Репозиторий публичный: никаких секретов, ключей, внутренних данных лаборатории, личных заметок.
- Закрытые коды IPP (RABBIT, TORBEAM, SPIDER, STRAHL) не публиковать и не пытаться добыть.
- Коммитить и пушить только по просьбе пользователя; чужие незакоммиченные изменения не откатывать.

## Установщик: главное

- Проверенная ASTRA: `e66f6ba13dd0160ed5b3dd37a46d0671cb81e85d` (2026-10-01); upstream `main` `6728111` тоже проходит.
  Меняя версию, править `ASTRA_REF` в `install_astra8.sh` и `ARG ASTRA_REF` в `installer/docker/Dockerfile` одновременно.
- Скачивается один коммит (`--depth 1`), поэтому `--ref` — ветка, тег или полный хэш.
- Патчи установщика (платформа `ubuntu`, флаги gfortran, OpenBLAS, патч парсера) накладываются на рабочую копию
  пользователя `~/astra/a8`, а не на `astra-src/`.
- Успех определяется по `>>> ASTRA normal exit >>>` и CDF в `ncdf_out/`: `exe/as_exe` всегда возвращает 0.
- Поддерживаются Ubuntu 22.04 и 24.04: не использовать то, чего нет в 22.04.
- После изменений: `bash -n`, повторный запуск на `~/astra` (`--no-apt -y`) и чистый контейнер
  `docker run --rm -v "$PWD/installer:/inst:ro" ubuntu:24.04 bash -c 'bash /inst/install_astra8.sh -y'`.
- Пользовательскую инструкцию `installer/README.md` и подробную `installer/docs/DETAILED.md` держать в актуальном состоянии.

## Среда

- WSL2 Ubuntu 24.04, `sudo` без пароля, WSLg для окон, Docker Desktop с интеграцией WSL.
- Рабочая установка ASTRA: `~/astra/a8`, команда `astra8`, журналы `~/astra/*.log`.
- `pkill -f` с шаблоном из той же команды убивает свою оболочку; останавливать по PID или `docker stop`.
- Скриншоты экрана Windows захватывают весь рабочий стол пользователя: удалять сразу.
